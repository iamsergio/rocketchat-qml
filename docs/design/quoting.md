# Quoting

A quote is a message whose text starts with an empty-label markdown link to the permalink of the quoted message: `[ ](http://host/channel/<room>?msg=<id>) my reply`. The server then adds an attachment, without a `type`, to the message: the quoted message's `text`, `md`, `author_name` (the username), `ts`, the `message_link`, and in `attachments` the quotes that message has itself. The reply's own `msg` and `md` keep the link. `rc_api` reads these entries (`Quote`: link, author, text, markdown, time, and `quoted_links`, the links of the nested quotes, whose own quotes are not kept), entry by entry like the files, so a malformed one is skipped.

- **`Site_Url`:** the server makes the attachment only if the permalink's host is its `Site_Url` setting: a link to `localhost` for `127.0.0.1`, or to the container's name that CI logs in with, makes no quote and the reply shows a bare link. So the links are built from `Site_Url`, and not from the address of the login. It is a public setting that needs no login (`RestClient::site_url`), so the core asks for it next to the version check, at login and at resume (`connect_checked`, both requests at once), and the session keeps it: a quote can be sent the moment the session is up. A server that has none, or a failed request (logged at warn, never failing the login), leaves the address of the login in its place.
- **Permalink:** `<site>/<channel|group|direct>/<room name, or the room id for a direct message>?msg=<id>`, built by a pure function (`rc_core::quote`). The server looks only at the host and at `msg`; the rest is for a browser. The quoted message is the `msg` of the link.
- **Hiding the links:** a message's `RichText` is made without them (`RichText::without_quote_links`): the leading empty-label links that are one of the message's quote links, the whitespace after them, and a first paragraph left empty. The same goes for a quote's own text with its `quoted_links`, so a quote of a quote shows the text of the inner message and none of its link. Only links the server made a quote of are dropped; one it didn't stays, and so does a link in the middle of a text. A body without `md` was made from the text, so it is made again from the stripped text.
- **Sending:** `send_message(room, text, quote)` quotes a sent text message of the open room; any other id is logged at debug and the message goes out without a quote. The local copy, shown at once as pending, carries a `Quote` made from the held message (its author, `RichText` and time, and the permalink), which the server's copy replaces. What goes to the server is built in one place from a message: `[ ](link) ` for each quote, in order, then the text. A retry and an edit use it too: the server drops the quotes of an edit whose text has no link, so an edit sends the links again, and "the same text" is the text as shown.
- **Qt side:** the `MessageList` model has a `quotes` role, a list of maps (`author`, the username; `bodyHtml`; `body`, as written; `time`, empty if unknown), made by `quote_view` and drawn again with the rest when the viewer or the emoji change, and a `canQuote` role (a sent text message, anyone's). `Room.send(text, quotedId)` takes the id to quote (empty for none) and `Room.messageAuthor` gives the name for the composer's bar.
- **QML:** the menu of a message opens for every message that can be quoted or changed, with Quote, Edit and Delete as it applies (items that don't apply take no space). A message draws its quotes above its text, each with a bar, the author, the time and the text; `msgBody` is hidden when the text is empty and there are files or quotes. The composer's `beginQuote` shows a bar with the author and one line of the text; Enter sends and drops it, as do Escape, its button and another room. Quoting while editing ends the edit first, and editing drops the quote. A layout with a child that fills the height takes the spare height of its column, so the bars set `Layout.fillHeight: false`.
- **Slint side:** a message row has `has-menu` (`can_quote || can_edit || can_delete`) and a `quotes` model of `QuoteRow`s, made by `rows.rs` only for a message that has quotes (the rest get the empty default model), with the quote's text rendered by `rich_markdown::styled` for the screen and by `rich_html::render` for the tests' `quoteBodyHtml`. The menu asks `can-quote` from Rust when it opens, like the edit and delete items. The composer asks `message-author` and `message-text` when `begin-quote` is called, passes the quoted id to `send`, and shows only the first line of the text by clipping it in a box that holds the whole text for the tests; its bar's height is computed from the theme, since the composer's own height is set from it.
- **Not done:** clicking a quote doesn't go to the quoted message, which needs the message to be loaded and in view. A quote is a copy: it doesn't follow edits of the quoted message.
